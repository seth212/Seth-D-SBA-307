
PROJECT NAME: Daily Drip Coffee Website


DESCRIPTION:
This is a simple website for a coffee brand called Daily Drip Coffee.
It allows users to explore coffee plans, learn about roasting options,
and sign up for a subscription.


FEATURES:

- Home page with hero section
- Coffee plan selection (Light, Medium, Dark roast)
- Simple navigation bar
- Basic animations for UI effects


TECHNOLOGIES USED:

- HTML
- CSS


FUTURE IMPROVEMENTS:
- Add user login system
- Add payment integration for subscriptions
- Improve animations and UI transitions
- Add backend for storing user data
